# Voorbeeldinvoer

`teamtrack_20s.mp4` is een ongewijzigde kopie van het al aanwezige fragment
`assets/clips20/F_20200220_1_0720_0750/clip_0000_0020.mp4` uit de hoofdrepository.
De naam verwijst naar de bestaande TeamTrack-bron `F_20200220_1_0720_0750`.
Het fragment is voorbeeldinvoer voor de app, geen onafhankelijke testset en
geen handmatig goedgekeurde kalibratie. Gebruik een zichtbaar, geschikt
velddeel en controleer de punten voor je de schoolkalibratie goedkeurt.
